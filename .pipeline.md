## 4) Visualize attention (bao cao)

Luu y: `visualize.py` chi dung cho Transformer, khong dung cho MLP baseline.

### Truong hop A: Chay mac dinh

```bash
python3 visualize.py
```

### Truong hop B: Chi dinh model cu the

```bash
python3 visualize.py --model results/model_Transformer_d128_ff256.pt
```

### Truong hop C: Chi dinh cau cu the

```bash
python3 visualize.py --model results/model_Transformer_d128_ff256.pt --sentence "this film is absolutely terrible"
```

### Truong hop D: Visualize tat ca Transformer (giu lai tung anh)

```bash
python3 visualize.py --model results/model_Transformer_d32_ff64.pt --sentence "this movie is not good"
mv results/attention_heatmap.png results/attention_heatmap_Transformer_d32_ff64.png

python3 visualize.py --model results/model_Transformer_d64_ff128.pt --sentence "this movie is not good"
mv results/attention_heatmap.png results/attention_heatmap_Transformer_d64_ff128.png

python3 visualize.py --model results/model_Transformer_d128_ff256.pt --sentence "this movie is not good"
mv results/attention_heatmap.png results/attention_heatmap_Transformer_d128_ff256.png
```

## 7) Bao toan artifacts de nop

Do `results/summary.json` se bi ghi de moi lan chay, nen nen luu snapshot sau moi lan chay:

```bash
RUN_TAG=$(date +%Y%m%d_%H%M%S)
mkdir -p results/archive_$RUN_TAG
cp results/model_*.pt results/archive_$RUN_TAG/
cp results/learning_curve_*.png results/archive_$RUN_TAG/
cp results/summary.json results/archive_$RUN_TAG/
cp results/attention_heatmap*.png results/archive_$RUN_TAG/ 2>/dev/null || true
```
